**作者：** 埃德温·勒菲弗　 **阅读日期：** 2024-12-08　 **阅读形式：** 纸质书

**个人评分：** 8/10　 **豆瓣评分：** [8.5/10](https://book.douban.com/subject/27601129/)（查询于 2026-07-31）

**简介：** 以职业投机者杰西·利弗莫尔的经历为原型，通过市场沉浮讲述趋势判断、仓位管理、交易纪律，以及贪婪、恐惧和自负如何影响投资决策。

**书评：** 叙事把交易经验放进一次次成功与失败之中，市场心理和风险纪律至今仍有启发。它更像一部带有传奇色彩的经验回忆录，而不是可直接照搬的交易教程；具体做法也需要结合现代市场环境重新判断。
